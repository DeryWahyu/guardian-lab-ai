# Audit sumber pengujian Indonesia, 6 November 2026

Penelusuran ini memeriksa publikasi dan metadata penerbit. Agent tidak membuka URL target dataset, mengirim formulir, menghubungi penulis, membuat reviewer, atau mengirim baris data ke LLM. Izin pengguna untuk memperbaiki model tidak menggantikan bukti label atau independensi pengujian.

Untuk sumber Mendeley terakhir, API publik menyediakan ukuran 32.312.600 byte dan SHA-256 `accb2dfbfd3329a8b5cb1b85dcad90314a660c272be755cb45d0f6865014b466`. Download di memori diverifikasi terhadap keduanya. CSV memiliki kolom `url,type`, dengan label literal `legitimate`/`phishing` dan hitungan tepat sesuai penerbit. [Audit skema](../../ml/reports/v6-indonesia-external-schema-audit.json) dan [amendemen mapping](../../ml/reports/v6-indonesia-external-schema-amendment.json) dibuat sebelum prediksi.

[Protokol](../../ml/reports/v6-indonesia-external-20261106-protocol.json) mengunci dua model, threshold, pemisahan domain, batas lima URL/domain, global maksimal 50.000 digest terkecil, dan subset seluruh hostname `.id` sebelum intake/scoring. Semua kasus novel dicadangkan untuk test. Tidak ada training, pemilihan ulang threshold, kalibrasi atau pemenang dari test ini. Subset `.id` tetap proxy suffix: bisa melewatkan serangan Indonesia pada `.com`/hosting privat, serta tidak membuktikan siapa pengguna yang ditargetkan.

Penelusuran ini belum menemukan dataset publik yang memenuhi seluruh syarat final holdout Indonesia proyek. Keterbatasan akses, label, relevansi, waktu dan independensi dicatat terpisah; tidak dinyatakan bahwa dataset semacam itu tidak ada. Pengguna sebelumnya menyatakan belum ada reviewer. Dua review manusia dan bukti koordinator tetap belum dapat digantikan oleh agent.
